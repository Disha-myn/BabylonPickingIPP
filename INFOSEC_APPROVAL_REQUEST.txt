Subject: InfoSec approval request — Babylon Picking IPP counter (mobile / HHD pickers only)

Hi InfoSec Team,

I am requesting approval for an internal productivity tool for warehouse picking on Babylon Picking. Pickers perform all assigned tasks on HHD (handheld device) or mobile only — no desktop. The tool shows a live hourly IPP counter on the Picking screen.

---

1. BUSINESS CONTEXT

- Users: Warehouse pickers on HHD / Android mobile devices only
- Application: Babylon Picking (https://babylon.mynt.myntra.com/Picking/*)
- Need: Real-time hourly IPP counter visible during picking
- Current gap: Mobile Chrome blocks bookmarklets; no pre-approved app can inject this counter on Babylon Picking

---

2. WHAT THE TOOL DOES

- Runs only on Babylon Picking URLs (allow-list hardcoded)
- Reads visible on-screen picking content to detect SKU/pick events (client-side only)
- Shows a small floating widget: hour, user, hourly count, average IPP
- Stores counts locally on device (localStorage only)
- Does NOT send data to external servers or third-party analytics
- Does NOT modify Babylon backend, APIs, or databases
- Does NOT capture passwords, OTPs, or payment data
- Counter is removed when picker leaves Picking or logs out

---

3. REQUESTED APPROVAL (mobile / HHD only)

Option A — Recommended (only viable automated option for HHD/mobile)

  Internal Android app: "Picking IPP"
  - Package ID: com.myntra.babylonpickingipp
  - Type: WebView wrapper that opens Babylon Picking and auto-runs approved counter script
  - Distribution: Internal MDM / sideload to warehouse HHD devices (not public Play Store)
  - Replaces: Unsupported bookmarklet workarounds on mobile Chrome
  - Source code available for security review

Option B — Fallback if app approval is delayed

  Manual IPP logging via approved Google Sheets / AppSheet
  - No automation on Babylon screen
  - Picker records count manually each hour
  - Fully within pre-approved stack but less accurate

We are NOT requesting desktop Chrome, bookmarklets, Tampermonkey, or Kiwi Browser — pickers do not use desktop for picking.
